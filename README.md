# 📻 《[电台里的悄悄话](https://hanananee.github.io/)》

午夜十二点，城市的喧嚣渐渐平息，FM98.5的电波里，传来主播阿哲温柔的声音：“欢迎收听《午夜悄悄话》，我是阿哲，今晚你有什么故事想和我分享？”

小夏是这个节目的忠实听众，她总是在十二点准时打开收音机，把音量调到最小，然后蜷缩在沙发上，听阿哲读听众的来信，讲那些温暖的故事。她写了很多封信，但从来没有寄出去过，那些信都被她锁在一个铁盒子里，藏在衣柜的最深处。

上个月电台举办听众见面会，小夏鼓起勇气去了。她站在人群后面，看着台上的阿哲，他穿着白色的衬衫，戴着一副黑框眼镜，笑起来像阳光一样温暖。散场时她不小心撞到了他，手里的笔记本掉在地上，阿哲帮她捡起来，看见笔记本上写着“给阿哲的信”，他的眼睛亮了一下，说“谢谢你喜欢我的节目”。

后来小夏开始给电台寄信，每封信的落款都是“一个喜欢听你声音的女孩”。阿哲会在节目里读她的信，有时会说“我好像认识这个女孩”，小夏坐在收音机前，脸一下子红了，像熟透的苹果。

上周小夏生日，她在信里说“今天是我的生日，我希望能听到你说一句生日快乐”。那天晚上阿哲在节目里说：“今天是小夏的生日，我在这里祝你生日快乐，愿你每天都像阳光一样灿烂。”小夏趴在沙发上，眼泪掉了下来，像断了线的珠子。

昨天我去电台找阿哲，他正在直播间里准备节目，桌上放着一个粉色的信封，上面写着“给阿哲的信”。他笑着说“这是小夏寄来的”，眼里满是温柔。直播间的窗外，城市的霓虹闪烁，像一片璀璨的星海。

现在小夏的信还在继续寄，阿哲也会在节目里读她的信，那些藏在电波里的悄悄话，像一颗颗星星，照亮了城市的夜空。

金句： 爱情有时不需要面对面的告白，电波里的声音、信纸上的文字，就足以传递最深的思念。
